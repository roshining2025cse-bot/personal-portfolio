# Personal Portfolio Website

## Overview
This is a Full Stack Personal Portfolio Website developed using React.js, Node.js, Express.js, and MongoDB Atlas. The project showcases personal information, skills, projects, and contact details while demonstrating frontend-backend-database integration.

## Technologies Used
- React.js
- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose

## Features
- Responsive portfolio design
- About section
- Skills section
- Projects section
- Contact section
- Resume download button
- REST API integration
- MongoDB database connectivity
- Project data storage and retrieval

## Installation

### Clone the repository

```bash
git clone https://github.com/roshining2025cse-bot/personal-portfolio.git
```

### Install frontend dependencies

```bash
cd frontend
npm install
npm run dev
```

### Install backend dependencies

```bash
cd backend
npm install
npm run dev
```
